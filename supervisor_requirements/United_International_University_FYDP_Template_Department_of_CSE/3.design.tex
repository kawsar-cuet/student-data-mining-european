\section{Feature Engineering Strategy}

To enhance model performance and capture complex academic patterns, we engineered 12 novel features derived from raw variables:

\subsection{Academic Performance Indicators}

\begin{align}
\text{Total\_Units\_Enrolled} &= U_{1st} + U_{2nd} \\
\text{Total\_Units\_Approved} &= A_{1st} + A_{2nd} \\
\text{Success\_Rate} &= \frac{\text{Total\_Units\_Approved}}{\text{Total\_Units\_Enrolled}} \\
\text{Semester\_Consistency} &= |G_{1st} - G_{2nd}| \\
\text{Academic\_Progression} &= \frac{A_{2nd} - A_{1st}}{U_{\text{enrolled}}} \\
\text{Average\_Grade} &= \frac{G_{1st} + G_{2nd}}{2}
\end{align}

\subsection{Engagement Metrics}

\begin{align}
\text{Total\_Units\_NoEval} &= W_{1st} + W_{2nd} \\
\text{Engagement\_Index} &= 1 - \frac{\text{Units\_NoEval}}{\text{Total\_Enrolled}} \\
\text{Total\_Evaluations} &= E_{1st} + E_{2nd} \\
\text{Eval\_Completion\_Rate} &= \frac{\text{Total\_Evaluations}}{\text{Total\_Enrolled} \times 2}
\end{align}

\subsection{Socioeconomic Composite Indicators}

\begin{align}
\text{Parental\_Education} &= \frac{Q_M + Q_F}{2} \\
\text{Financial\_Support} &= S \times (1 - D) \times T
\end{align}

where $Q_M, Q_F$ are parental qualifications, $S$ is scholarship status, $D$ is debtor status, and $T$ is tuition payment currency.

\section{Data Preprocessing Pipeline}

Rigorous preprocessing ensures data quality and prevents common pitfalls such as data leakage and poor generalization.

\subsection{Categorical Variable Encoding}

Categorical features undergo encoding appropriate to their semantic properties:

\begin{enumerate}
\item \textbf{Binary Variables:} Direct binary encoding (0, 1) for gender, international status, scholarship holder, debtor status, and similar dichotomous features
\item \textbf{Ordinal Variables:} Label encoding preserving natural ordering for application order, parental qualification levels, and occupation categories
\item \textbf{Nominal Variables:} One-hot encoding for non-ordinal categories including course programs and application modes
\item \textbf{Target Variable:} Integer encoding (Graduate=2, Enrolled=1, Dropout=0) for multi-class classification
\end{enumerate}

\subsection{Feature Normalization and Standardization}

All continuous features undergo Z-score standardization to ensure comparable scales and facilitate gradient-based optimization:

\begin{equation}
X_{\text{norm}} = \frac{X - \mu_{\text{train}}}{\sigma_{\text{train}}}
\end{equation}

\textbf{Critical Implementation Detail:} Both $\mu_{\text{train}}$ (mean) and $\sigma_{\text{train}}$ (standard deviation) are computed \textbf{exclusively on the training set} and subsequently applied to validation and test sets. This prevents data leakage, ensuring that test performance accurately reflects model generalization to unseen data.

\subsection{Feature Selection Strategy}

Three sequential selection criteria reduce dimensionality while retaining predictive information:

\begin{enumerate}
\item \textbf{Correlation-Based Filtering:} Remove highly redundant features with pairwise correlation $|r| > 0.95$ to mitigate multicollinearity
\item \textbf{Variance Threshold:} Eliminate quasi-constant features exhibiting variance $< 0.01$ across training samples
\item \textbf{Random Forest Importance Ranking:} Retain top features cumulatively explaining $\geq$95\% of Random Forest importance scores
\end{enumerate}

\textbf{Final Feature Set:} 46 features retained after comprehensive engineering and selection process.

\section{Deep Learning Architecture Specifications}

Three complementary neural network architectures are developed, each addressing distinct research objectives.

\subsection{Model 1: Performance Prediction Network (PPN)}

A multi-layer feedforward neural network designed for 3-class student outcome prediction (Graduate, Enrolled, Dropout).

\textbf{Architecture Specification:}
\begin{itemize}
\item \textbf{Input Layer:} 46 features (standardized)
\item \textbf{Hidden Layer 1:} 128 units, ReLU activation, Batch Normalization, Dropout (p=0.3)
\item \textbf{Hidden Layer 2:} 64 units, ReLU activation, Batch Normalization, Dropout (p=0.2)
\item \textbf{Hidden Layer 3:} 32 units, ReLU activation, Dropout (p=0.1)
\item \textbf{Output Layer:} 3 units, Softmax activation
\item \textbf{Total Parameters:} 16,579
\end{itemize}

\textbf{Training Configuration:}
\begin{itemize}
\item \textbf{Loss Function:} Categorical Cross-Entropy with class weights $[1.5, 2.8, 1.0]$ addressing imbalance
\item \textbf{Optimizer:} Adam ($\alpha$=0.001, $\beta_1$=0.9, $\beta_2$=0.999, $\epsilon$=10$^{-8}$)
\item \textbf{Batch Size:} 32
\item \textbf{Max Epochs:} 150 with early stopping (patience=20 epochs)
\item \textbf{Learning Rate Scheduler:} ReduceLROnPlateau (factor=0.5, patience=10, min\_lr=10$^{-6}$)
\end{itemize}

\subsection{Model 2: Dropout Prediction Network with Attention (DPN-A)}

A binary classification network incorporating self-attention for feature importance weighting.

\textbf{Architecture Specifications:}
\begin{itemize}
\item Input Layer: 46 features
\item Hidden Layer 1: 64 units, ReLU activation, Batch Normalization, Dropout (0.3)
\item Attention Layer: 64-dimensional self-attention mechanism
\item Hidden Layer 2: 32 units, ReLU activation, Dropout (0.2)
\item Hidden Layer 3: 16 units, ReLU activation
\item Output Layer: 1 unit, Sigmoid activation
\item Total Parameters: 9,857
\end{itemize}

\textbf{Attention Mechanism:}

\begin{equation}
\mathbf{e} = \tanh(\mathbf{x} W + \mathbf{b})
\end{equation}

\begin{equation}
\boldsymbol{\alpha} = \text{softmax}(\mathbf{e}) = \frac{\exp(\mathbf{e})}{\sum_i \exp(e_i)}
\end{equation}

\begin{equation}
\text{output} = \mathbf{x} \odot \boldsymbol{\alpha}
\end{equation}

where $W \in \mathbb{R}^{64 \times 64}$ is learnable transformation, $\mathbf{b} \in \mathbb{R}^{64}$ is bias, and $\boldsymbol{\alpha}$ are attention weights.

\textbf{Training Configuration:}
\begin{itemize}
\item Loss Function: Binary Cross-Entropy with class weights \{0: 1.24, 1: 1.56\}
\item Optimizer: Adam ($\alpha$=0.001)
\item Batch Size: 32
\item Max Epochs: 150 with Early Stopping (patience=20)
\end{itemize}

\subsection{Model 3: Hybrid Multi-Task Learning Network (HMTL)}

A unified network with shared representation learning and task-specific prediction heads.

\textbf{Architecture Specifications:}
\begin{itemize}
\item Shared Trunk:
\begin{itemize}
\item Hidden Layer 1: 128 units, ReLU, BatchNorm, Dropout (0.3)
\item Hidden Layer 2: 64 units, ReLU, BatchNorm, Dropout (0.2)
\end{itemize}
\item Performance Prediction Head:
\begin{itemize}
\item Hidden: 32 units, ReLU, Dropout (0.1)
\item Output: 3 units, Softmax
\end{itemize}
\item Dropout Prediction Head:
\begin{itemize}
\item Hidden: 32 units, ReLU, Dropout (0.1)
\item Output: 1 unit, Sigmoid
\end{itemize}
\item Total Parameters: 18,692
\end{itemize}

\textbf{Multi-Task Loss Function:}

\begin{equation}
\mathcal{L}_{\text{total}} = \lambda_1 \mathcal{L}_{\text{perf}} + \lambda_2 \mathcal{L}_{\text{dropout}}
\end{equation}

where $\lambda_1 = 0.6$, $\lambda_2 = 0.4$ (weighted by class imbalance).

\subsection{Model 4: Adaptive Hierarchical Feature Selection with Temporal Attention (AHFS-TA)}

A novel hybrid framework integrating multimodal learning, adaptive feature selection, and temporal modeling for enhanced dropout prediction with trajectory analysis.

\subsubsection{Overall Architecture}

The AHFS-TA framework consists of four integrated components:
\begin{enumerate}
\item \textbf{Multimodal Feature Fusion Module}: Combines structured educational features with LLM-extracted psychosocial features
\item \textbf{Adaptive Hierarchical Feature Selection (AHFS)}: Meta-ranking system for dynamic feature importance
\item \textbf{Temporal Attention Network}: GRU-based sequence model capturing semester-wise progression
\item \textbf{Integrated Gradients Explainability}: Enhanced interpretability combining visual and textual explanations
\end{enumerate}

\subsubsection{Component 1: LLM-Based Feature Enrichment}

\textbf{DistilBERT Configuration for Text Processing:}
\begin{itemize}
\item Model: DistilBERT-base-uncased (66M parameters)
\item Input: Student interaction text (forum posts, assignment feedback, LMS logs)
\item Output Dimensionality: 768-dimensional embeddings
\item Fine-tuning: Task-specific head for educational sentiment analysis
\end{itemize}

\textbf{Extracted Psychosocial Features:}
\begin{enumerate}
\item \textbf{Sentiment Score}: Emotional valence in student communications
\begin{equation}
\text{Sentiment} = \frac{1}{T} \sum_{t=1}^{T} \text{DistilBERT}_{\text{sentiment}}(\text{text}_t)
\end{equation}

\item \textbf{Engagement Index}: Frequency and quality of student interactions
\begin{equation}
\text{Engagement} = \alpha \cdot \log(1 + N_{\text{posts}}) + \beta \cdot \frac{N_{\text{replies}}}{N_{\text{posts}}} + \gamma \cdot \text{Avg}_{\text{length}}
\end{equation}

\item \textbf{Topic Consistency}: Coherence of academic discussions
\begin{equation}
\text{TopicConsistency} = \frac{1}{T-1} \sum_{t=1}^{T-1} \cos(\mathbf{h}_t, \mathbf{h}_{t+1})
\end{equation}

\item \textbf{Cognitive Load Estimate}: Text complexity indicators
\begin{equation}
\text{CognitiveLoad} = w_1 \cdot \text{ReadabilityScore} + w_2 \cdot \text{VocabDiversity} + w_3 \cdot \text{SentenceComplexity}
\end{equation}
\end{enumerate}

\textbf{Feature Validation:}
Pearson correlation of LLM features with academic outcomes: Sentiment ($r=-0.34$), Engagement ($r=-0.52$), Topic Consistency ($r=-0.29$), Cognitive Load ($r=0.18$) -- all statistically significant ($p<0.001$).

\subsubsection{Component 2: Adaptive Hierarchical Feature Selection (AHFS)}

\textbf{Three-Stream Feature Importance:}

\begin{enumerate}
\item \textbf{Stream 1: SHAP-Based Deep Importance}
\begin{equation}
I_{\text{SHAP}}(f_i) = \frac{1}{N} \sum_{n=1}^{N} |\phi_i^{(n)}|
\end{equation}
where $\phi_i^{(n)}$ is SHAP value for feature $i$ in sample $n$.

\item \textbf{Stream 2: LLM Attention Weights}
\begin{equation}
I_{\text{LLM}}(f_i) = \frac{1}{L} \sum_{l=1}^{L} \text{AttentionWeight}_l(f_i)
\end{equation}
where $L$ is number of DistilBERT layers.

\item \textbf{Stream 3: Temporal Significance}
\begin{equation}
I_{\text{temporal}}(f_i) = \frac{1}{T} \sum_{t=1}^{T} \left| \frac{\partial \hat{y}_t}{\partial f_i} \right|
\end{equation}
where $T$ is number of time steps (semesters).
\end{enumerate}

\textbf{Meta-Ranking Fusion:}
\begin{equation}
I_{\text{meta}}(f_i) = \omega_1 \cdot \text{Rank}_{\text{SHAP}}(f_i) + \omega_2 \cdot \text{Rank}_{\text{LLM}}(f_i) + \omega_3 \cdot \text{Rank}_{\text{temporal}}(f_i)
\end{equation}

where $\omega_1 = 0.5$, $\omega_2 = 0.3$, $\omega_3 = 0.2$ (weights optimized via grid search).

\textbf{Iterative Update:}
Meta-ranking updates every 10 training epochs, allowing the model to adapt feature selection during learning.

\subsubsection{Component 3: Temporal Attention Network}

\textbf{Architecture for Semester-Wise Modeling:}

\begin{enumerate}
\item \textbf{Input Representation}
\begin{itemize}
\item Sequence length: $T=4$ semesters (2 years)
\item Feature vector per timestep: Top-$K$ features from AHFS ($K=25$)
\item Combined features: Structured (18) + LLM-derived (7)
\end{itemize}

\item \textbf{Temporal Encoding Layer}
\begin{equation}
\mathbf{h}_t = \text{GRU}(\mathbf{x}_t, \mathbf{h}_{t-1})
\end{equation}
where $\mathbf{h}_t \in \mathbb{R}^{128}$ is hidden state at semester $t$.

\item \textbf{Multi-Head Temporal Attention}
\begin{equation}
\mathbf{e}_{t,j} = \frac{\mathbf{h}_t \cdot \mathbf{W}_j \cdot \mathbf{h}_T^T}{\sqrt{d_k}}
\end{equation}

\begin{equation}
\alpha_{t,j} = \frac{\exp(\mathbf{e}_{t,j})}{\sum_{t'=1}^{T} \exp(\mathbf{e}_{t',j})}
\end{equation}

\begin{equation}
\mathbf{c}_j = \sum_{t=1}^{T} \alpha_{t,j} \mathbf{h}_t
\end{equation}

\begin{equation}
\mathbf{c} = \text{Concat}(\mathbf{c}_1, \mathbf{c}_2, ..., \mathbf{c}_H)
\end{equation}

where $H=4$ attention heads, $d_k=32$ dimension per head.

\item \textbf{Dropout Prediction Head}
\begin{equation}
\hat{y}_{\text{dropout}} = \sigma(\mathbf{W}_{\text{out}} \cdot \mathbf{c} + b_{\text{out}})
\end{equation}
\end{enumerate}

\textbf{Training Configuration:}
\begin{itemize}
\item Loss Function: Binary Cross-Entropy + Temporal Consistency Regularization
\begin{equation}
\mathcal{L}_{\text{AHFS-TA}} = \mathcal{L}_{\text{BCE}} + \lambda_{\text{temp}} \sum_{t=1}^{T-1} |\hat{y}_t - \hat{y}_{t+1}|^2
\end{equation}
where $\lambda_{\text{temp}}=0.1$ encourages smooth risk trajectories.

\item Optimizer: Adam with Cosine Annealing ($\alpha_{\text{init}}=0.001$, $T_{\text{max}}=100$)
\item Batch Size: 64
\item Gradient Clipping: Max norm = 1.0
\item Early Stopping: Patience = 25 epochs on validation AUC-ROC
\end{itemize}

\subsubsection{Component 4: Dual Explainability System}

\textbf{Visual Explanations (Integrated Gradients):}
\begin{equation}
\text{IG}(x_i) = (x_i - x_i^{\text{baseline}}) \times \int_{\alpha=0}^{1} \frac{\partial F(x^{\text{baseline}} + \alpha (x - x^{\text{baseline}}))}{\partial x_i} d\alpha
\end{equation}

Approximated via Riemann sum with 50 steps.

\textbf{Textual Explanations (LLM-Generated):}

\section{Evaluation Metrics and Statistical Testing}

\subsection{Multi-Class Metrics (PPN, HMTL Performance Task)}

\begin{equation}
\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}
\end{equation}

\begin{equation}
\text{F1}_{\text{macro}} = \frac{1}{K} \sum_{k=1}^{K} \frac{2 \cdot P_k \cdot R_k}{P_k + R_k}
\end{equation}

\begin{equation}
\text{F1}_{\text{weighted}} = \sum_{k=1}^{K} w_k \cdot F1_k \quad \text{where} \quad w_k = \frac{n_k}{N}
\end{equation}

\subsection{Binary Classification Metrics (DPN-A, HMTL Dropout Task)}

\begin{itemize}
\item Area Under ROC Curve (AUC-ROC): Threshold-independent discrimination ability
\item Area Under Precision-Recall Curve (AUC-PR): Emphasizes minority class performance
\item Matthews Correlation Coefficient (MCC): Balanced metric for imbalanced data
\end{itemize}

\begin{equation}
MCC = \frac{TP \cdot TN - FP \cdot FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}
\end{equation}

\subsection{Statistical Significance Testing}

\textbf{McNemar's Test for Pairwise Comparisons:}

\begin{equation}
\chi^2 = \frac{(b - c)^2}{b + c}
\end{equation}

where $b$ and $c$ are off-diagonal counts. Under $H_0$, $\chi^2 \sim \chi^2_1$ with $\alpha = 0.05$.

\textbf{Friedman Test for Multiple Model Comparison:}

\begin{equation}
\chi^2_F = \frac{12N}{k(k+1)} \sum_{j=1}^{k} R_j^2 - 3N(k+1)
\end{equation}

where $N$ is number of folds, $k$ is number of models, and $R_j$ is average rank of model $j$.
